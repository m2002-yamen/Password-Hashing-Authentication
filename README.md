# Password Hashing Authentication

This project demonstrates password hashing and user authentication using Python.

## Features

- User registration
- Random salt generation
- SHA-256 password hashing
- Password and salt combination before hashing
- Text file storage
- User login verification
- Detection of incorrect passwords

## Files

- `password_auth.py` - Main Python program
- `users.txt` - Stores username, salt, and hashed password

## Run

```bash
py password_auth.py
